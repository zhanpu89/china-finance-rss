# 精准定位规则

> **【通用方法论 · 项目资产】** 本文件随工具分发的版本是跨项目通用的专家标准。安装到项目后，整个 `.opencode/` 即成为你的**项目资产**——可直接改写本文件沉淀团队/项目专属规则，也可在项目 `opencode.json` 的 `instructions` 中增删规则条目。工具不预设任何项目特定内容。

增量/Bug 修复：禁止不经定位直接全局扫描。

**免定位：** 单文件修改 / 异常堆栈已指向具体文件 / 纯文本修改

**标准定位：** 1.模块(doc/detailed/) → 2.层级(视图/业务/数据/接口/配置) → 3.候选文件(1~3个并行读)

**例外：** 详设无对应模块 / 候选文件无相关逻辑 / 跨模块 Bug → 说明原因后可扩大

**输出：** `📍 模块 → 层级 → 候选文件`
