# 安全 / 数据库 / 特殊集成

> 每个决策都要给理由和阈值，不是背参数。安全与数据库选型属于**低可逆决策**，必须在 SAD 中留下 ADR。

## 安全

| 组件 | 决策锚点 | 理由/阈值 |
|------|---------|----------|
| 认证 | JWT + Refresh Token + Redis 黑名单（按 LC-001 见 `overlays.md` 语言节） | Access 短时（15~30min），Refresh 长时（7~30 天）；登出/改密即拉黑 |
| 授权 | RBAC 三表模型（用户/角色/权限） | 角色权限可演进；**禁止角色枚举嵌入用户表**（改权限要改代码/迁移） |
| 密码 | BCrypt 哈希存储 | 自带盐 + 自适应 cost；**禁止** MD5/SHA1 明文-hash 弱算法 |
| 敏感数据 | AES-256-GCM 加密存储，密钥放 KMS/环境变量 | 可认证加密防篡改；密钥禁入库/代码仓库 |
| 传输 | TLS 1.2+；敏感接口全链路加密 | 中间层不留明文 |
| 攻击面 | SQL 注入/CSRF/XSS/限流/参数校验 | 全入参白名单校验；写操作 CSRF token；外部 API 限流 |

**安全必答：** 认证方式、授权粒度、密码/Token 方案、敏感字段清单、合规要求（等保/GDPR）——任一缺失记 P1。

## 数据库

| 项 | 决策锚点 | 阈值 |
|----|---------|------|
| 命名 | snake_case 表名，复数名词 | 团队统一，评审 grep 可验 |
| 软删除 | `deleted_at` 字段 | 业务需审计/可恢复时用；纯日志型可硬删 |
| 时间戳 | `DATETIME(3)` 毫秒精度 | 排序/去重需要毫秒；UTC 存储防时区错乱 |
| 枚举 | `TINYINT + COMMENT` 或字符串常量 | 禁魔法数字；枚举值变更要同步代码常量 |
| 索引 | 覆盖索引/复合索引/最左前缀 | 查询 WHERE/JOIN/ORDER 列建复合索引；**禁无索引大表** |
| 分库分表 | 何时拆 | 单表预估 >5000 万行 或 单实例 TPS 逼近上限才拆；数据量小不拆 |
| 连接池 | 配置上限 | 峰值并发估算 + 缓冲；禁无上限连接泄漏 |

**数据库必答：** 一致性级别、跨表事务需求、分库分表阈值、备份/恢复策略。选型有 ADR（见 tech-selection.md）。

## 特殊集成

| 集成 | 决策锚点 | 关键点 |
|------|---------|--------|
| 区块链 | hash 上链，数据链下存储 | 只上缩略/凭证 hash 防成本膨胀；完整数据存 DB |
| 支付 | 异步回调 + 幂等表 + 超时撤销 | 回调幂等（订单维幂等键）；下单→超时未回调→撤销/关闭 |
| 文件存储 | OSS/S3 + CDN + 签名 URL | 限制大小 + 类型白名单；私有文件用签名 URL 时效防公开 |

**集成必答：** 每个集成方有幂等方案、失败重试/补偿、超时上限——缺任一记 P1。
