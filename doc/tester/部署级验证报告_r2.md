## 4. SSE 流验证（端口 8054）

**建组：**
```
$ curl -X POST -H 'Content-Type: application/json' -d '{"codes":["sh600519"],"fields":["quote"]}' http://localhost:8054/stream/subscriptions
{"sid": "f48d0a1207e6", "codes": ["sh600519"], "fields": ["quote"]}      # HTTP 201
```

**订阅流（首次 6s 窗口无帧 → 复核后确认为采样窗口问题，非缺陷）：**
- SSE 帧为**推送节拍驱动**：`tick_interval()` = L1 = **8s**（交易时段）；`STREAM_PING_INTERVAL=20`（队列空才发 ping）。因此 6s 窗口预期可能什么都收不到。
- **25s 窗口重测（sid=de387c7d05cc）：收到 4 个 `event: quote` 帧**，含真实贵州茅台行情：

```
event: quote
id: 1789525983436
data: {"ts":1789525983436,"items":{"sh600519":{"quote":{"code":200,"msg":"","data":{"secu_code":"sh600519","secu_name":"贵州茅台","last_px":1260.43,"change_px":-12.32,"open_px":1273.93,"high_px":1274.98,"low_px":1260.32,"trade_status":"TRADE",...},"sector_name":"食品饮料行业"}}}}

--- event 统计 ---
4 event: quote
```

- `curl_exit=124` = 被 `timeout` 主动掐断的长连接（预期行为，非错误）

**结论：** ✅ SSE 建组（201）+ 订阅流推送（`event: quote` ×4，真实数据）均正常。

指标旁证：`stream_tick_duration_ms=0.29`（远低于 8s 预算，无退化解）、`stream_frame_peak_bytes=878`。
`stream_slow_client_total=1` 系本次验证主动断流所致，**非缺陷**。
